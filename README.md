### 🚀 Featured Engineering Projects

#### 💰 [OmniLedger B2B SaaS](link_do_repositorio_aqui)
*A multi-tenant corporate billing and real-time financial reconciliation ecosystem.*
* **The Challenge:** Ensuring absolute transactional consistency and UI reactivity without relying on heavy frontend JS frameworks.
* **The Engineering:** Built with **Ruby on Rails + Hotwire**. It leverages an immutable ledger based on *double-entry bookkeeping* in **PostgreSQL**, row-level tenant isolation, and massive background processing via **Solid Queue** paired with **Turbo Streams (WebSockets)** to update progress bars in real time. Deployed on autonomous infrastructure using **Kamal 2** and **Docker**.

#### 📡 [NexusStream Telemetry Grid](link_do_repositorio_aqui)
*A distributed multi-region platform for massive telemetry ingestion and IoT monitoring.*
* **The Challenge:** Handling severe, continuous data load spikes from edge sensors without blowing up server RAM or bottlenecking the database.
* **The Engineering:** Developed in **Elixir/OTP**. It parses raw binary network packets via TCP/UDP ports using `ranch`, manages data streams under heavy stress using **Broadway** and **GenStage** (applying native *backpressure*), and maintains a geographically synchronized cluster state via **Mnesia**. The analytical dashboard runs 100% on **Phoenix LiveView** powered by `:telemetry` events.
